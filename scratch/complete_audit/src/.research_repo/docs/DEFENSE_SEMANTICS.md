# Phase 8: Defense Semantics and Calibration

This document explicitly defines the semantics and mathematical structure of the implementations of Adaptive Feature Poisoning (AFP), Randomized Smoothing (RS), and Feature Squeezing (FS) developed in Phase 8.

## Historical Calibration Failures and Repairs
During early Phase 8 execution, an initial semantic interpretation incorrectly conflated *pre-projection bounds crossings* with *final invalid values*. Because standardized sparse feature distributions tightly cluster around their absolute boundaries, additive zero-centered perturbations mathematically push significant percentages (>40%) of the cells below the minimum bounds. 

A tightly-scoped Semantics Repair was executed to strictly separate:
1. **Pre-Projection Diagnostics:** (e.g., `proposal_out_of_bounds_fraction`)
2. **Final Invalid Fractions:** Non-finite cells or bounds violations remaining *after* strict numerical projection.

Subsequent diagnostic analysis demonstrated that bounds projection (clipping) was empirically irrelevant to the recall collapse observed at large intensities. The Random Forest model is acutely sensitive to additive perturbations at the originally proposed noise scales, causing recall to plummet identically whether the proposals are clipped or unclipped.

## Final Calibration Success
Following the repairs and refinement of the intensity grids, Phase 8 Calibration successfully completed with the following authoritative selections:
- **AFP**: epsilon_base=0.0003, alpha=0.5 (Recall: 0.8121969414397613)
- **RS**: sigma=0.0002 (Recall: 0.8217083177918687)
- **FS**: squeezing_intensity=2 (Recall: 0.9403207758299142)

- **Baseline Recall:** 0.9483401715777695
- **Invalid Constraints:** 0 post-projection bounds violations, 0 NaNs/Infs, 0 protected feature changes. 
- **Protocol Adherence:** The 0.80 recall boundary was strictly adhered to.

## Semantics Proved by Implementations

### 1. Feature Mask Semantics
The operative rule for feature perturbation is exactly "63 eligible numerical features with 15 explicitly protected fields". While many eligible features represent integer counts in the underlying dataset, they are treated as continuous vectors during perturbation according to the approved methodology. The explicitly protected binary flag features remain among the 15 protected fields. No dynamic exclusion of integer fields is performed.

### 2. Stateless Randomness
All noise generated by AFP and RS strictly relies on a deterministic hashing strategy (`hashlib.sha256`) of a structured key:
`key = f"{seed}_{attack}_{defense}_{batch_id}_{ensemble_id}"`. 
Python's `hash()` memory-level stochasticity is completely sidestepped. Base and RA configurations receive the exact same fundamental standard noise tensor before intensities scale them, guaranteeing robust cross-experiment comparability.

### 3. Adaptive Feature Poisoning (AFP)
`sigma_safe = np.maximum(np.abs(sigma), 1.0e-6)` ensures exact lower bounds, and `delta = np.abs(x - mu) / sigma_safe` allows targeted cell-level variance scaling. The thesis formula operates multiplicatively exactly as configured.

### 3. Randomized Smoothing (RS)
Executes `11` explicit copies. A tie is mathematically impossible given the binary outputs. Chunk-size invariance guarantees memory-safety (`chunk_size=500` used) on large prediction batches without altering RNG results.

### 4. Feature Squeezing (FS)
`d = max(0, 6 - int(intensity))` correctly maps intensities via bankers-rounding directly to scaled eligible boundaries.
