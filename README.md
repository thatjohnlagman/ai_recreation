# AI Recreation Study: Baseline for Thesis Replication

This repository contains the standalone replication codebase and evaluation platform for our AI replication study. It reproduces and evaluates the **Adaptive Feature Perturbation (AFP)** defense mechanism against black-box query-based adversarial probing attacks on Machine Learning-based Intrusion Detection Systems (IDS).

## Project Overview

This project was built to serve as a baseline evaluation framework for our thesis:
- **Streamlit Validation Dashboard (`app.py`)**: A live traffic visualization and threat sandbox demonstrating perturbation defenses.
- **Evaluation Notebook (`final_evaluate_defenses.ipynb`)**: Complete replication study evaluating defenses under bisection queries.
- **NumPy Random Forest Notebook (`final_train_eval_rf.ipynb`)**: A standalone evaluation of the custom NumPy-based classifier implementation.
